# Investor Office – Sistema de Gestión de Inversores  
Aplicación web desarrollada para gestionar datos de clientes, generar contratos personalizados y administrar información legal/comercial asociada a procesos de inversión.

## Descripción general
Investor Office es una plataforma que centraliza y automatiza la administración de inversores.  
Permite cargar datos personales, financieros y societarios, y a partir de esa información genera documentos legales (contratos de apertura de cuenta, poderes, formularios regulatorios, etc.) de forma dinámica y estandarizada.

---

## Funcionalidades principales

### Gestión de clientes
- Alta y edición de inversores (personas físicas y jurídicas)
- Datos personales, domicilio, actividad, perfil financiero, vínculos, etc.
- Soporte para múltiples tipos de clientes (individuo / empresa)

### Generación automática de contratos
- Plantillas dinámicas para varias entidades (Morgan Stanley, Pershing, etc.)
- Contratos diferenciados según el tipo de cliente
- Campos completados automáticamente desde la base de datos
- Descarga de documentos listos para firma

### Panel de control
- Visualización de clientes cargados
- Historial de contratos generados
- Reportes y listados
